Recording instructions and how to put the clips in the game
  1. Choose a quiet room. Keep your mic about a hand span away, slightly to one side.
  2. Read only the line. Leave half a second of quiet at each end. Record two or three takes: natural, bigger, then softer if helpful. Do not read bracketed laughter directions.
  3. Keep raw takes in a separate folder. Choose one take per cue and name it exactly as shown. No music or effects are needed.
  4. WAV mono, 48 kHz, 16- or 24-bit works well. MP3, OGG and M4A are also indexed; codec support depends on the browser. A phone recording is fine to start with.
  5. Put final takes in public/audio/voice/. For example: c00-awakening-01.wav. Use only one audio file per cue.
  6. Run npm run recordings from the project folder, then refresh the game. Starting the dev server or building the game also updates the recording index.
  7. Use the circular arrow in a cutscene to replay a take. “Play scene” follows the voice or readable caption timing. Skip, pause, mute and volume all work with recorded dialogue.

There are no fabricated voice recordings. Unrecorded lines use captions. Estimated silent-autoplay story time: 9.1 minutes on the first playthrough, excluding gameplay. Actual takes, reading and skips change that.
