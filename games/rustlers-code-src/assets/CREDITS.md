# Asset Credits — The Rustler's Code

Every external asset in this game (models, textures, sounds, music, fonts) gets
a row here **in the same session it's added** — see the `asset-pipeline` skill.
Before deploy, every file in `public/assets/` must have a row in this table.

| Asset | Author | Source URL | Licence | Used for |
|---|---|---|---|---|

*As of M11: the table is empty on purpose. Every model, texture, picture and
sound in the game is generated by the game's own code (voxel-style shapes,
canvas-drawn signs, WebAudio-synthesized sound). Nothing was downloaded, so
there is nothing to credit — yet. Any future external asset gets a row here
in the same session it's added.*
